# Daily Activity Tracker

A modern web application for tracking your daily activities with beautiful visualizations, productivity insights, and streak tracking.

## Features

- Log activities with title, description, time, mood, and tags
- View activities in daily, weekly, and monthly formats
- Productivity charts and streak tracking
- Search and filter activities
- Secure authentication with Clerk

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Firebase (Firestore)
- Clerk (Authentication)
- Tailwind CSS
- Recharts
